# PureLibm Coefficient Scripts

This directory contains the Sollya/Gappa scripts that generate polynomial
coefficients for PureLibm's correctly-rounded elementary functions.  Each
script is self-contained and can be replayed with:

    sollya <name>.sollya

## Script format

Each script must:

1. Set the working precision high enough for the target (e.g., `prec = 200;`).
2. Define the approximation interval (after range reduction).
3. Call `remez()` (or equivalent) with the degree and interval.
4. Print the coefficients as C99 hex float literals suitable for
   copy-paste into the corresponding source file.
5. Optionally verify the approximation error with `dirtyinfnorm()`.

## Naming conventions

- Filename: `<function-name>.sollya`  (e.g., `sinf.sollya`, `expf.sollya`)
- Function script: `<function-name>.sollya`

## Coefficient comment format in source code

Every magic constant in the source must include a comment block tracing
it to its generation script:

```c
// Generated by: Sollya
// Script:    coeff/sinf.sollya
// Command:   remez(sin(2*pi*x), 5, [-2^-12, 2^-12]);
static const double CR_SINF_C1 = 0x1.921fb54442d17p-3;
```

Constants derived analytically (e.g., ln(2) decomposition, 1/ln(2))
must note their provenance in a comment.

## Verification

Before committing a script, run it with Sollya and verify that the
output coefficients match the source code exactly (bitwise).  This
should be done manually for M2; a CI check may be added later.
